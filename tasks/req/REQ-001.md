# Goal

实现 ADR-008 规定的三个 CI 质量门禁脚本，使 G1–G3 可在本地执行。

# In Scope

- `scripts/release-audit.sh` — 扫描 hardcoded paths/secrets + 必需文件检查
- `scripts/check-req-coverage.sh` — REQ/BUG frontmatter 校验 + 状态机规则
- `scripts/extract-prompts.py` — 提取 backend/app/ 中所有 LLM prompt 到 eval/prompts-snapshot.md

# Out of Scope

- GitHub Actions workflow（PHASE-000 结束后配置）
- G4/G5 测试脚本（REQ-002 覆盖）

# Acceptance Criteria

- `bash scripts/release-audit.sh` 在干净仓库上退出码 0
- `bash scripts/check-req-coverage.sh` 对空 `tasks/req/` 退出码 0
- `python scripts/extract-prompts.py --update` 生成 `eval/prompts-snapshot.md`
- `python scripts/extract-prompts.py` 检查模式在 snapshot 最新时退出码 0
