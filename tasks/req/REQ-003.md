# Goal

提供 KB 生命周期管理脚本：校验、摄入向量库、构建知识图谱、图像转 markdown。

# In Scope

- `scripts/validate_kb.py` — frontmatter 校验（必填字段、doc_id 格式、subtopic 匹配 YAML）
- `scripts/ingest_kb.py` — KB markdown → BGE-M3 向量 → ChromaDB
- `scripts/build_kg.py` — KB docs → Neo4j KBDoc 节点 + BELONGS_TO 关系
- `scripts/convert_images.py` — raw/ 图像 → Claude Vision → KB markdown（含 --dry-run）

# Acceptance Criteria

- `python scripts/validate_kb.py` 对 knowledge_base/docs/ 现有文件退出码 0
- `python scripts/ingest_kb.py` 可导入（ChromaDB 未运行时报连接错误，非导入错误）
- `python scripts/build_kg.py` 可导入（Neo4j 未运行时报连接错误，非导入错误）
- `python scripts/convert_images.py --dry-run` 退出码 0
