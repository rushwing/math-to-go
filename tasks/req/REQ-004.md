# Goal

提供 dev 和 prod 环境的 Docker Compose 编排文件，使用固定镜像 tag 保证可复现。

# In Scope

- `docker-compose.dev.yml` — ChromaDB 0.6.x + Neo4j 5.26-community（固定 tag）
- `docker-compose.prod.yml` — Qdrant 1.13.x + Neo4j 5.26-community（固定 tag）
- 所有服务含 healthcheck 配置

# Acceptance Criteria

- `docker compose -f docker-compose.dev.yml pull` 无报错
- `docker compose -f docker-compose.dev.yml up -d` 启动成功
- Neo4j 健康检查：`wget -qO- http://localhost:7474`
- ChromaDB 健康检查：`GET http://localhost:8001/api/v1/heartbeat`
