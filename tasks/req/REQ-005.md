# Goal

建立 FastAPI 应用骨架：配置管理、CORS 中间件、健康检查端点，以及所有子包的 `__init__.py` 占位文件。

# In Scope

- `backend/app/config.py` — pydantic-settings，读取 .env，与 .env.example 完全对应
- `backend/app/main.py` — FastAPI app factory，CORS 中间件，`GET /health`
- `backend/app/{agents,api,api/routes,kg,models,rag,services,utils}/__init__.py` — 空占位

# Acceptance Criteria

- `uv run uvicorn app.main:app` 在 backend/ 目录下启动无报错
- `GET /health` → `{"status": "ok"}`
- `uv run mypy app --strict` 无错误（空 __init__ 可能有 missing stubs；用 `ignore_missing_imports` 处理）
- `uv run ruff check app` 无报错
