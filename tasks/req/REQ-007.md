# Goal

提供标准化的任务模板，使 Agent 和人工开发者可以快速创建符合 harness 规范的 REQ/BUG/TC 文件。

# In Scope

- `tasks/features/FEATURE-template.md` — REQ 文件模板，含完整 frontmatter schema
- `tasks/bugs/BUG-template.md` — BUG 文件模板
- `tasks/test-cases/TC-template.md` — TC 文件模板
- `tasks/req/` — REQ 文件目录（ADR-008 §2 规定位置）
- `tasks/archive/done/` — 完成 REQ 归档目录

# Acceptance Criteria

- 三个模板文件存在，包含 requirement-standard.md §3 规定的所有 frontmatter 字段
- `tasks/req/` 和 `tasks/archive/done/` 目录存在
