# Purpose

Verifies AC1: `claim-req.sh` accepts `AGENT_UID=optimizer-001` when the target REQ is owned by `optimizer-001` and its status is listed in the optimizer handles from the registry.

# Preconditions

- `harness/agent-registry.yml` contains `optimizer-001`.
- `optimizer-001` handles `req_impl`.
- The test creates a temporary REQ file, for example `tasks/req/REQ-998.md`, with `status: req_impl` and `owner: optimizer-001`.
- The temporary REQ file is removed after the test.

# Steps

1. Create the temporary REQ file with valid required frontmatter and `owner: optimizer-001`.
2. Run `AGENT_UID=optimizer-001 bash scripts/claim-req.sh REQ-998`.
3. Capture stdout, stderr, and exit code.
4. Delete the temporary REQ file.

# Expected Result

- Exit code is `0`.
- stdout contains `OK: REQ-998 is claimable by optimizer-001`.
- stdout reports `status : req_impl` and `owner  : optimizer-001`.
- stderr is empty.

# Notes

- The implemented test should use `try/finally` or an equivalent cleanup trap so the temporary REQ does not remain in the working tree.
