# Purpose

Verifies AC2: `claim-req.sh` accepts `AGENT_UID=evaluator-001` when the target REQ is owned by `evaluator-001` and its status is listed in the evaluator handles from the registry.

# Preconditions

- `harness/agent-registry.yml` contains `evaluator-001`.
- `evaluator-001` handles `req_impl_review`.
- The test creates a temporary REQ file, for example `tasks/req/REQ-998.md`, with `status: req_impl_review` and `owner: evaluator-001`.
- The temporary REQ file is removed after the test.

# Steps

1. Create the temporary REQ file with valid required frontmatter and `owner: evaluator-001`.
2. Run `AGENT_UID=evaluator-001 bash scripts/claim-req.sh REQ-998`.
3. Capture stdout, stderr, and exit code.
4. Delete the temporary REQ file.

# Expected Result

- Exit code is `0`.
- stdout contains `OK: REQ-998 is claimable by evaluator-001`.
- stdout reports `status : req_impl_review` and `owner  : evaluator-001`.
- stderr is empty.

# Notes

- This TC should fail if evaluator handles are not read from the registry or if `req_impl_review` is omitted from the evaluator handles list.
