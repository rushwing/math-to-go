# Purpose

Verifies AC3: `claim-req.sh` fails closed when `AGENT_UID` is not present in the active agent registry.

# Preconditions

- The main registry does not contain `unknown-uid`.
- The test creates a temporary REQ file, for example `tasks/req/REQ-998.md`, with an otherwise valid status and owner.
- The temporary REQ file is removed after the test.

# Steps

1. Create a temporary REQ file with `status: req_impl` and `owner: unknown-uid`.
2. Run `AGENT_UID=unknown-uid bash scripts/claim-req.sh REQ-998`.
3. Capture stdout, stderr, and exit code.
4. Delete the temporary REQ file.

# Expected Result

- Exit code is `1`.
- stderr contains `Unknown UID`.
- stdout does not contain a claimable `OK` message.

# Notes

- The test should assert the unknown UID is rejected before any status-specific success path can run.
