# Purpose

Verifies the claim path rejects legacy owner values after migration: model names such as `claude` are not valid agent UIDs.

# Preconditions

- The main registry contains UID values such as `optimizer-001`, `evaluator-001`, and `human-001`.
- The main registry does not contain `claude`.
- The test creates a temporary REQ file, for example `tasks/req/REQ-998.md`, with `status: req_impl` and `owner: claude`.
- The temporary REQ file is removed after the test.

# Steps

1. Create the temporary REQ file with `owner: claude`.
2. Run `AGENT_UID=claude bash scripts/claim-req.sh REQ-998`.
3. Capture stdout, stderr, and exit code.
4. Delete the temporary REQ file.

# Expected Result

- Exit code is `1`.
- stderr contains `Unknown UID` or equivalent registry lookup failure text for `claude`.
- stdout does not contain a claimable `OK` message.

# Notes

- This TC covers the claim script path. TC-008-07 covers the coverage-check path for all legacy owner values.
