# Purpose

Verifies AC5: `check-req-coverage.sh` passes when REQ owner fields use valid registered UID values.

# Preconditions

- REQ-008 implementation has migrated all active REQ files from legacy owners to registered UIDs or `unassigned`.
- `harness/req-constants.sh` derives `REQ_VALID_OWNERS` from `harness/agent-registry.yml`.
- No temporary invalid REQ or BUG files are present in the repository.

# Steps

1. Run `bash scripts/check-req-coverage.sh` from the repository root.
2. Capture stdout, stderr, and exit code.

# Expected Result

- Exit code is `0`.
- stdout contains `REQ coverage check passed`.
- No output line reports `invalid owner`.

# Notes

- This is the broad happy-path validation for the migrated repository state.
