# Purpose

Verifies AC7: `harness/agent-registry.yml` exists and defines the required initial agent UID records with mandatory fields and non-empty handles.

# Preconditions

- REQ-008 implementation has added `harness/agent-registry.yml`.
- The test can parse the registry using the same no-new-dependency policy as the implementation, or a test-only YAML parser already available in the test environment.

# Steps

1. Open `harness/agent-registry.yml`.
2. Locate records for `optimizer-001`, `evaluator-001`, and `human-001`.
3. For each record, inspect `uid`, `role`, `model`, `description`, and `handles`.
4. Verify each `handles` value is non-empty.

# Expected Result

- The registry file exists.
- All three required UIDs are present exactly once.
- Each required record contains `uid`, `role`, `model`, `description`, and `handles`.
- Each `handles` list contains at least one status value.

# Notes

- This TC intentionally checks registry structure, not the behavior of scripts that consume the registry. Behavioral coverage is in TC-008-01 through TC-008-07 and TC-008-10 through TC-008-11.
