# Purpose

Verifies AC8: `.env.example` contains the default `AGENT_UID=optimizer-001` setting and explanatory comments that name the other initial UID values.

# Preconditions

- REQ-008 implementation has updated `.env.example`.
- The test can read `.env.example` as plain text from the repository root.

# Steps

1. Open `.env.example`.
2. Search for a non-comment line exactly matching `AGENT_UID=optimizer-001`.
3. Search comment lines for `evaluator-001`.
4. Search comment lines for `human-001`.

# Expected Result

- `.env.example` exists.
- A non-comment `AGENT_UID=optimizer-001` line is present.
- At least one comment line mentions `evaluator-001`.
- At least one comment line mentions `human-001`.

# Notes

- This is a static L1 structure check and requires no harness fixture setup.
